# gp-registry

A Game Printer registry: static files, not signed, that the Donkey Kong page at https://nes-donkey-kong.intentius.workers.dev installs from. It replaces `lex00/rivetrodeo`. The files are made by `gp registry` from the [gameprinter](https://github.com/lex00/gameprinter) tool, so don't edit them by hand.

It holds `lex00/donkey-kong`, played from a ROM you own, and `lex00/turnips`, a clay look for it from [lex00/turnips](https://github.com/lex00/turnips).

It also holds `ddmoney420/orangutan-arcade`, Orangutan Arcade, a look for it by ddmoney420 from [ddmoney420/orangutan-arcade-theme](https://github.com/ddmoney420/orangutan-arcade-theme), licensed under CC BY 4.0.

No ROM data is here. A publish is refused when any file holds bytes of a ROM the package names.

To have a theme of yours published here, open an issue with a link to its repo.
